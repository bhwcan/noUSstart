# noUSstart
Snowrunner edit save file to skip starting in the US maps of Michigan and Alaska. It will give you one copy of the trucks found in Michigan and Alaska however it does not discover the trucks. It will give you all the upgrades found in Michigan and Alaska. It sets the rank at 21, gives you 300,000 in money, and starts the game in Taymur. 

## WARNING Backup up save files before running. It will remove trucks from storage and upgrades found after Alaska. Start with a newly created save file.

### Instructions
1. Create a new save in Snowrunner
2. Open a Command Prompt
3. Run "path to exe"\noUSstart "path to save files"\CompleteSave.dat
4. Play Snowrunner and have fun
